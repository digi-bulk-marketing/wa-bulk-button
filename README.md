# Wa Bulk Button

Wa Bulk Button by Wa Bulk Button.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/wa-bulk-button/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Wa Bulk Button** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/wa-bulk-button/releases/latest) and reinstall.
